# Chat Voice Bot

Озвучивает в Twitch-чате **первые сообщения зрителей (ФМ)** и **сообщения модераторов** голосами
узнаваемых персонажей — каждый раз случайным. Как у Братишкина, только с персонажами.

- Голоса клонируются локально по 10-секундному образцу (**F5-TTS**, запасной — **XTTS-v2**) — бесплатно, без лимитов.
- Звук и субтитры «🎭 Артас: текст» выводятся в OBS через страницу-оверлей — VB-CABLE не нужен.
- Модераторы управляют из чата: `!tts skip`, `!tts stop`, `!tts start`, `!tts clear`, `!tts volume 60`.
- Удалённое модератором сообщение или забаненный зритель не будут озвучены (пауза 2 с перед озвучкой).
- Ссылки, @упоминания, «аааааа», спам повторами и сообщения из одних эмоутов чистятся.
- Панель управления в браузере: пропуск, пауза, громкость, очередь, тестовое сообщение.

```
Twitch IRC ──► фильтр ФМ/модераторов ──► очередь (модеры первыми) ──► F5-TTS на GPU ──► оверлей OBS
     │                                        ▲                                       (звук + субтитры)
     └── удаление/бан ────────────────────────┘
```

## Быстрый старт (Windows) — один двойной клик

**`setup.bat`** делает всё сам:
1. ставит Python 3.11 (если нет), PyTorch с CUDA и библиотеки, спрашивает ваш канал Twitch;
2. скачивает русскую модель F5-TTS;
3. нарезает голоса персонажей из готового списка `voices.csv` (Артас, Иллидан, Керриган, Диабло, Аларак,
   Мурадин, Декард Каин, Сидорович): скачивает ролик, вычищает музыку, сам находит речь и расшифровывает её;
4. озвучивает мемные фразы всеми голосами и открывает папку `out\f5` — слушайте.

Первый раз — 30–60 минут (качается ~6–8 ГБ моделей). Повторный запуск безопасен: готовое пропускается.

Дальше:
- **`start.bat`** — бот подключается к чату. **Звук идёт в колонки** (устройство Windows по умолчанию):
  вы его слышите, а OBS записывает/стримит через «Звук рабочего стола», как игру или музыку.
  Субтитры: в OBS *Источник → Браузер*, `http://127.0.0.1:8790/overlay`, 1920×1080.
- **`test-chat.bat`** — проверка без Twitch: пишете сообщения сами.
- Свои персонажи (Губка Боб, Шрек…): ссылка в `voices.csv` → **`add-voices.bat`** → **`test-voices.bat`**.

Если что-то упало — скопируйте текст ошибки из окна и пришлите.

## Установка вручную

1. **Python 3.11** с [python.org](https://www.python.org/downloads/) (при установке отметьте *Add to PATH*).
2. В папке `chat-voice-bot`:

   ```bat
   python -m venv .venv
   .venv\Scripts\activate
   pip install torch==2.8.0 torchaudio==2.8.0 --index-url https://download.pytorch.org/whl/cu126
   pip install -r requirements-f5.txt -c constraints.txt
   python download_models.py
   ```

   Проверка, что видеокарта видна: `python -c "import torch; print(torch.cuda.is_available())"` → `True`.

   XTTS-v2 лучше ставить в **отдельное** окружение (у пакетов бывают конфликты версий):
   `python -m venv .venv-xtts`, затем те же команды, но `pip install -r requirements-xtts.txt`.

3. `copy config.example.toml config.toml` и впишите свой канал в `[twitch] channel`.

### Модели

- **F5-TTS (русская):** `python download_models.py` скачает сам и пропишет пути. Если автовыбор ошибся — откройте [Misha24-10/F5-TTS_RUSSIAN](https://huggingface.co/Misha24-10/F5-TTS_RUSSIAN),
  вкладка *Files*. Скачайте чекпоинт (`.safetensors`/`.pt`) и `vocab.txt` нужной версии в `models/f5_russian/`
  и пропишите пути в `[engine] f5_ckpt_file` / `f5_vocab_file`. Сверьтесь с описанием модели:
  если там указана другая архитектура — поменяйте `f5_model` (например `F5TTS_Base`), и если модели не нужны
  ударения `+` — поставьте `f5_accent = false`. Остальное (вокодер, RUAccent) скачается само при первом запуске.
- **XTTS-v2** скачивается сам (~2 ГБ) при первом запуске. Лицензия модели — некоммерческая (CPML).

### Голоса

Автоматически: ссылки в `voices.csv` → `python add_voices.py`. Вручную: положите персонажей в `voices/` —
инструкция и советы по образцам в [voices/README.md](voices/README.md).

## Шаг 1. Выбрать движок: тест A/B

```bat
python voice_test.py
```

Озвучит 5 мемных фраз каждым голосом через F5 и XTTS → `out\f5\...wav`, `out\xtts\...wav`,
в конце — средняя скорость. Послушайте и выберите движок (`[engine] name`). Свои фразы:
`python voice_test.py --phrases "Привет, чат!" "Я тут впервые"`.

## Шаг 2. Запуск бота

```bat
python -m voicebot
```

Это подключение к чату Twitch из `config.toml`. Для проверки:
- `python -m voicebot console` — без Twitch, сообщения печатаете сами;
- `python -m voicebot --engine dummy console` — ещё и без нейросети: только проверить OBS и оверлей.

После запуска:
- **Панель:** <http://127.0.0.1:8790/> — пропуск, пауза, громкость, очередь, кнопка «Озвучить» для теста.
- **Звук** по умолчанию идёт в колонки (`[audio] output = "device"`), OBS берёт его из «Звука рабочего стола».
  Другое устройство (например `device = "CABLE Input"` для VB-CABLE): список — `python -m voicebot devices`.
- **Субтитры в OBS:** *Источник → Браузер*, URL `http://127.0.0.1:8790/overlay`, ширина 1920, высота 1080.
- Хотите голос отдельной дорожкой в микшере OBS: `output = "overlay"` и в свойствах источника «Браузер»
  галочка **«Управлять звуком через OBS»**. Тогда сами вы его услышите, только включив в OBS
  *Расширенные свойства звука → Мониторинг: «Прослушивание и вывод»*.

## Команды модераторов

| Команда | Что делает |
|---|---|
| `!tts skip` (`!tts скип`) | пропустить текущее |
| `!tts stop` (`!tts стоп`) | пауза: замолчать и не озвучивать дальше |
| `!tts start` (`!tts старт`) | снять паузу |
| `!tts clear` | очистить очередь |
| `!tts volume 60` | громкость 0–100 |
| `!tts voices` | список голосов (ответ в чат — только если задан токен) |

## Настройки, которые стоит знать (`config.toml`)

- `voices.moderator_mode = "fixed"` — у каждого модератора свой постоянный голос (узнаваемо);
  закрепить вручную: `[voices.moderator_voices] ник = "arthas"`.
- `filters.moderator_prefix = "~"` — озвучивать только те сообщения модеров, что начинаются с `~`.
- `filters.banned_words` — сообщения с этими словами не озвучиваются вообще.
- `queue.delay_seconds` — сколько ждать перед озвучкой (время модерам удалить сообщение).
- `engine.f5_nfe_step = 16` — почти вдвое быстрее, чуть хуже качество.

## Если что-то не так

- **`torch.cuda.is_available()` = False** — переустановите PyTorch командой выше (с `--index-url .../cu126`),
  обновите драйвер NVIDIA.
- **Ошибка про `torchcodec`/FFmpeg** — значит, встал PyTorch 2.9+. Переустановите 2.8 командой выше
  (`setup.bat` делает именно так).
- **`add_voices` не скачивает видео** — обновите загрузчик: `.venv\Scripts\python -m pip install -U yt-dlp`.
- **Русский звучит как акцент/каша** — не указан русский чекпоинт F5 (`f5_ckpt_file`), либо не совпадает `f5_accent`
  с тем, на чём обучена модель.
- **Голос «плывёт» или бормочет** — образец короче 5 с, с музыкой, или `ref.txt` не совпадает с речью.
- **В оверлее нет звука в обычном браузере** — браузер блокирует автозвук: кликните по красной плашке. В OBS этого нет.
