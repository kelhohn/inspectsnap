# Голоса персонажей

Каждый голос — отдельная папка:

```
voices/
  arthas/
    ref.wav      ← 8–12 секунд чистой речи персонажа
    ref.txt      ← дословно то, что сказано в ref.wav
    voice.toml   ← необязательно
  spongebob/
    ref.wav
    ref.txt
    voice.toml
```

`voice.toml` (все поля необязательные):

```toml
name = "Губка Боб"   # как подписывать в оверлее
weight = 1.0         # как часто выпадает: 2.0 — вдвое чаще, 0.5 — вдвое реже
speed = 1.0          # 1.1 — быстрее, 0.9 — медленнее
enabled = true       # false — временно выключить
fish_id = "..."      # только для движка fish: ID голоса из Fish Audio или ссылка на его страницу
```

Для движка `fish` образец не обязателен: папка с одним `voice.toml`, где есть `fish_id`, — уже голос.
Без `fish_id` Fish клонирует ваш `ref.wav`.

## Как сделать хороший образец (от этого зависит 90% качества)

1. **Источник:** русская озвучка (дубляж) — её ваши зрители и узнают.
2. **Длина 8–12 секунд.** F5-TTS обрезает образец до ~12 с; меньше 5 с — голос «плывёт».
3. **Чисто:** без музыки, взрывов, второго персонажа и эха. Если музыка есть — прогоните через
   [Ultimate Vocal Remover](https://github.com/Anjok07/ultimatevocalremovergui) (модель MDX/Kim Vocal) и возьмите вокал.
4. **Характерная интонация.** Как персонаж говорит в образце, так он будет говорить всё: спокойный Артас →
   спокойный, кричащий → кричащий. Губке Бобу — бодрый кусок со смехом, Артасу — пафосный.
5. **Формат:** WAV, моно, 24 кГц или выше. Нарезать удобно в Audacity: выделить → *Файл → Экспорт → WAV*.
6. **`ref.txt` — точная расшифровка** с теми же словами (знаки препинания помогают интонации).
   Без `ref.txt` F5-TTS сам распознает речь через Whisper, но это медленнее и иногда ошибается.

Проверить новый голос: `python voice_test.py --voices arthas`.
